## Decision summary

The exact CI command, `vendor/bin/phpstan analyse --memory-limit=1G --no-progress`, reported **152 errors** before remediation. The prior baseline accounted for 404 legacy findings but had drifted: new findings and unmatched/count changes caused the failure.

Two findings were fixed rather than accepted: the missing `SchoolClass::campus()` relationship (runtime failure in student lookups) and the verification notification's overly narrow declared return type (framework contract incompatibility). The reviewed consolidated baseline now accounts for **556 findings in 364 exact file/message groups**. The apparent increase from 152 is not new debt: 152 was the unaccepted delta on top of the prior 404-entry-count baseline. After consolidation the CI command reports zero unignored errors.

No finding classified as security-, tenant-isolation-, authorization-, data-integrity-, or runtime-critical was baselined. Sensitive IAM, tenant, assessment, result, and student findings were reviewed as Eloquent generic/cast/query-alias inference limitations or static typing debt; existing security and domain tests remain required controls.
