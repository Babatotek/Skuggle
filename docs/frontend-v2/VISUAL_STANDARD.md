# Visual standard

The approved Students reference establishes “calm intelligence”: light neutral surfaces, restrained indigo actions, cool borders, semantic status washes, modest elevation, strong alignment, and readable operational typography.

The Students pilot uses a 28–32px page title, four compact metric cards, one filter/action toolbar, 52–60px desktop rows, status badges, and a mobile student-card projection. Each page has one primary action. Tenant accent is bounded to identity and primary action tokens; status and focus colors remain protected.
